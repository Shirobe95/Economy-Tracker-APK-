# DEC-003 · Modelo financiero y ahorro

## Decisión

Separar REAL, COMPROMETIDO, PREVISTO y OBJETIVO; fecha_prevista y fecha_real; capacidad estimada de ahorro, objetivo de ahorro y ahorro real. El dinero sobrante no equivale automáticamente a ahorro.

## Contexto y motivo

Contrato inicial autorizado por Andy para una aplicación personal Android. No se atribuyen decisiones a documentación previa inexistente.
