# DEC-002 · Sin backend ni login

## Decisión

No hay backend, API, Supabase, autenticación remota, login, cuentas online ni sincronización cloud. Biometría/PIN futuros protegen localmente la app.

## Contexto y motivo

Contrato inicial autorizado por Andy para una aplicación personal Android. No se atribuyen decisiones a documentación previa inexistente.
