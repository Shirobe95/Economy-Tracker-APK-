# Sistema visual v0.1

Diseño PALIKO es el nombre del lenguaje visual para Economy Tracker; no supone copiar la aplicación PALIKO.

Principios: interfaz oscura, fondo grafito/azul muy oscuro, acentos azul/cian, tarjetas discretas, jerarquía fuerte de métricas, tipografía limpia, poco ruido visual, navegación inferior Android, iconografía Material clara, colores semánticos y acciones frecuentes accesibles con una mano.

Sin subtítulos ornamentales. Mostrar métricas únicamente cuando existan datos reales.

| Semántica | Color |
| --- | --- |
| Ingreso / positivo | Verde |
| Gasto / negativo | Rojo |
| Pendiente | Amarillo |
| Interfaz / previsto | Azul/cian |
| Información secundaria | Gris |

Centralizar colores, fondos, superficies, estados, radios, espaciados, tipografía, botones, tarjetas, campos y navegación en lib/app/theme. Los valores concretos del bootstrap son una primera materialización técnica de estos principios; requieren revisión visual humana.
