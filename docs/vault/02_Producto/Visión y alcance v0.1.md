# Visión y alcance v0.1

Fuente: prompt de fundación autorizado por Andy el 2026-09-05. Este conjunto documental pasa a ser la referencia canónica local. En la fundación no se habían recibido mockups; en ECON-000C se incorporan los aprobados, documentados en [[Pack visual v0.1]].

Economy Tracker es una aplicación Android personal para control y previsión financiera. Debe gestionar gastos, gastos recurrentes, ingresos, salarios, clientes, proyectos, cobros, calendario financiero, cuentas, objetivos de ahorro, informes y previsión financiera.

Debe permitir conocer:

1. Cuánto dinero hay actualmente.
2. Cuánto se ha gastado.
3. Cuánto se ha cobrado.
4. Qué falta cobrar.
5. Qué falta pagar.
6. Cómo terminará el mes.
7. Cuánto se proyecta tener en 3, 6, 12 y 24 meses.
8. Si se está cumpliendo el objetivo de ahorro.

ECON-000B prepara documentación, estructura Flutter, navegación, tema y persistencia técnica. No implementa CRUD, modelo financiero definitivo, recurrencias, clientes/proyectos funcionales, salarios reales, previsión, objetivos, informes, biometría ni backups. Sin backend, login, cuentas online, sincronización o IA.
